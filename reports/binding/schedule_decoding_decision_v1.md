Final DEV contains no version-3 examples. Version 4 appears only in slot 0; slot 1 is always version 2. Slots 2 and 3 use only versions 1 and 2. At initialization, every version label is 1. Counts, constants and restricted slot coverage therefore limit any claim about general version discrimination. The explicit version heads predict current version numbers; definition and parent heads predict statement indices. Converting their outputs to complete variable@version identities using oracle source maps would be an oracle-assisted postmetric, and obsolete statements’ complete identities were not decoded.

There are five DEV graph families, with unequal numbers of numeric, lexical and query relatives. The three weighting seeds are dependent readout variations. Neither the difference between row and graph averages nor the model ordering supplies a population significance claim. Random-prefix controls preserve prefix consistency but change class marginals and need not form lawful graphs. The three-TRAIN-family support diagnostic is separate from historical behavioral reliability gates.
