# First learned structural and algebraic readouts: corrected control

This version amends the program-shuffle control before any activation result or fit. The first queued CPU fitting/refresh attempts were canceled before starting; capture inputs, source, job and all real-label primary comparisons remain unchanged. The original plan and job records are preserved.

This adaptive discovery study follows the [two-family preparation](relationship_preparation_findings_v2.md). It uses the fixed 1,944-row algebraic copy-routing bank, with 1,296 training rows in 18 components and 648 development rows in nine components. Its 81 graphs are split 54/27, and numeric/rewiring/lexical relatives stay in their component. The earlier routing bank is not pooled as independent replication. No language-model outcome on this bank is used to choose this protocol.

## Capture and fitting

Capture the cached Llama 3.1 8B Instruct checkpoint at commit `0e9e39f249a16976918f6564b8830bc894c89659`, using native chat, a fixed execution instruction and literal assistant prefix `Output:`. Record all eight assignment endpoints and the final prompt position, at raw blocks 8, 16, 24 and 31. Validate exact prompt tokens and visible character/token prefixes, with explicit left-padding position IDs and no token containing future code at a checkpoint. Use BF16 SDPA, no KV cache, and prefill-only decoder forwards without the vocabulary head or response generation. Report 1,944 new case prefills separately from zero generated responses and the actual number of batch attempts.

Strict identical-prefix numerical checks compare only cases within the same actual batch and padding/position geometry. Other identical-prefix differences are diagnostics rather than evidence of future information. Record the comparison counts, fixed numerical tolerance, model/backend, device/UUID, memory, timings and checksums. The later readout stage uses no additional language-model call.

Fit only three saved sites in this first study: after initialization (statement 3), after the four copies (statement 7), and the final prompt position (site 8). The other captured sites are retained for later studies, not silently selected here. At each site compare all four hidden layers with 4,096 signed character-ngram surface features (sizes 3–8) from exactly the same visible prefix. This is 15 feature banks and three fixed weighting seeds, normally 45 shared ridge factorizations; report any distinct target-mask factorization separately.

Use float64, unweighted training-only StandardScaler, fixed summed weighted squared-error ridge alpha 100, and independent output columns. Seeds 11, 29 and 47 assign positive structural-group weights using the existing exponential-plus-1e−6 recipe, mean-normalized in float32 and then cast to float64. Every numeric/lexical/rewiring relative in a component has the same weight. Seeds are sensitivity fits, not replications. No tuning or selection on development model performance is performed.

Targets include four scalar current-value heads, four 32-class categorical value heads over −16…−1 and 1…16, pair/triple algebraic heads, versioned edge/ancestry heads and four three-way copy-parent heads. Mask undefined/future/impossible edges; report constant relations rather than counting them as learned recovery. Version identity and current/obsolete status are largely determined by this fixed scaffold, so they cannot support a general version-resolution claim. Parent argmax scores reconstruct a valid graph under the scaffold; unconstrained binary-edge predictions are a separate diagnostic.

## Controls and retained evidence

The label-prior comparator uses training targets only. The surface comparator uses the same 4,096-coordinate budget. A within-component shuffle alone leaves three parent choices unchanged. Independently shuffling all 36 canonical programs also creates contradictory control labels for the three future-parent variants that share the same initialization prefix. A source-only check found this contradiction in all 1,944 rows under all three seeds; it is a control-task defect, not a model result.

The corrected control first deranges complete components separately within each split, then permutes the 12 initialization-prefix/numeric-base blocks in each mapped component. Within a mapped base, permute the three first-copy-parent variants; keep both lexical forms tied. Every identical initialization prefix now receives one consistent numeric control state. The actual bank has no cross-component collisions among these initialization prefixes. Preserve one complete donor program per row across all target columns and sites, maintaining its graph/value/relation coherence and unweighted marginals. Report any weighted-marginal differences without a matching claim. Seed remains `fit_seed + 100000`; retain every donor mapping.

Evaluate shuffled tasks against separately shuffled development targets; they are control tasks rather than original-label primary contrasts. Explicitly verify initialization-prefix consistency for each seed before fitting. The qualification applies to the fitted sites 3, 7 and 8. Earlier partial prefixes are captured but not fitted and need a new control-visibility check if used later.

This amendment changes only the control task. It does not change the 18 training-qualified primary algebraic cells, four-family metric, categorical value-derived comparator, real structural parent targets, feature banks, alpha, weighting seeds, conditional bootstrap, or any source/model input. The corrected source-only prefix oracle can attain 1.0 on its labels; this software check is excluded from model decoding evidence.

Save every fitted parameter, score, prediction, training/case identity, class-support table and donor mapping. Reconstruct scores exactly from saved parameters. Keep a bounded completion manifest pinning source/configuration/data and rich results, with a separate explicitly pinned scientific-result reader. Log jobs, failures and completion automatically. Success would establish accessible relationships under these readouts on copy-only, fixed-order, neutral-name discovery programs.
