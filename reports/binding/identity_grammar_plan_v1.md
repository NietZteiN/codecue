## Score-only decoder

Four roots initialize counters c=(1,1,1,1). For each of four copy events, choose destination owner d and read owner p. The parent identity is 4*p+c[p]-1 before the write, including self-copies. The new write identity is 4*d+c[d], after which c[d] increments. A write is available only when c[d]<4, matching the represented version-1-through-4 global codebook. The primary grammar permits self-copy and has 64,512 complete paths. The secondary grammar prohibits p=d and has 20,412 paths. There is no profile-union or per-program constraint. The version cap is a representational restriction; it excludes the 1,024 paths requiring version 5.

Cross two evidence views with both grammars. Joint evidence sums the eight selected raw float64 joint-class scores with equal weight. Owner-marginal evidence first sums all four version cells of each owner exactly, then scores the selected owners; the grammar supplies versions externally. This is a score ablation of the same joint tables, not a separately trained representation. No calibration, temperatures, normalization, tuning or outcome-based rule selection. These ridge scores are utilities, not probabilities, so this is maximum summed score, not probabilistic MAP.

Core decoding receives only two N-by-4-by-16 score tables and the declared evidence/grammar flags. No source text, ground truth, SSA, actual schedule, per-row profile or query enters its interface. Exact dyadic integer arithmetic preserves the float64 inputs' exact values, global optimum and ties. Tie order is event-interleaved (d0,p0,d1,p1,...), encoded by four base-16 digits 4*d+p. Any nonfinite cell invalidates the whole case: emit missing predictions and count every defined target wrong, without pruning or fallback. Store exact objective numerator/exponent pairs without pickle.

## Controls and interpretation

An explicit comparator parses only visible LHS/RHS owner sequences and applies the same counter convention; it is expected to reconstruct all real identities perfectly by construction. Source-owner/TRAIN-version-prior scores also receive all four decoders; their owner-only view is expected to recover the visible owners exactly. This distinguishes external source reconstruction from hidden-score reconstruction.

Retain original sham scores evaluated against their own original truth, measure that truth's global lawfulness and consequent constrained exact ceiling, and separately evaluate the same sham predictions against real truth as a cross-task negative control. Unlawful sham truth makes constrained-sham accuracy unsuitable as matched selectivity. No source-oracle relabeling.

Report whole-four-write, whole-four-parent and whole-eight exact recovery, each head, correction/harm transitions against both original free decision rules, and free-joint validity strata. Preserve all DEV graph groups, count profiles, slots and assignment/parent status strata. No uncertainty intervals or tuning on DEV families. Neural improvements with the decoder establish only decoder-assisted reconstruction. Version recovery in the owner-only view can come entirely from external counting. They do not establish maintained variable state, causal use, natural decoding or unfamiliar-program generalization.
