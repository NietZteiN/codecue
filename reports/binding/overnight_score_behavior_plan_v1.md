# Posthoc relationship decoding and answer behavior

This discovery analysis is selected after reading the October 27–28 relationship results. It uses existing saved probe scores and generated responses from the same familiar four-root/four-copy scaffold. It adds no model queries, probe fits, saved-parameter prediction replays, raw activation access or sealed outcomes. It is not a confirmatory study or a test of natural causal use.

Use both cached checkpoints at the nominated original layers: Llama 3.1 8B block24 and CodeLlama34B block36. Preserve all original results and completion receipts. Join exact case IDs and metadata from the literal `query_twins` panel and the numeric_draw=0 subset of `computed_roots`. All7,290 responses per checkpoint must have valid identities and original scoring before analysis. Report only the2,430 DEV cases per model:1,944 literal cases and486 computed cases. Keep the nine structural components as uncertainty units; lexical twins, numeric draws, query variants and three weighting seeds are dependent relatives.

For sites3,7,8 and seeds11,29,47, read only the fixed primary hidden and source score banks. Compare complete parent graph correctness, queried parent correctness where defined, and independently decoded queried-value correctness with the observed full-answer correctness. Include source-direct graph and source-value comparators. At site3, a queried-slot value probe refers to that slot’s initial binding, not the eventual copied answer. Sites7/8 refer to final bindings. Retain this value-reference label in the results. A graph is undefined at site3 and must be omitted there. Invalid generated answers remain incorrect, with invalid-response strata retained.

Average binary joint masses across the three fixed fits before deriving any conditional probability. For example, report mean[(1-answer_correct)*graph_correct] and sum(answer_correct*mean_fit(graph_correct))/sum(mean_fit(graph_correct)). Fractional fit-averaged graph correctness is not converted to a majority graph. Report support and conditional denominators explicitly. Keep all predeclared source-form/query/site/backend cells; use2,000 whole-component bootstrap draws, seed117, without refitting or multiplicity correction. Require at least1,900 valid draws out of the same2,000 component draws for every conditional interval; do not redraw to obtain favorable support. Empty or insufficient bootstrap denominators must be reported, not replaced with invented intervals. Joint masses remain defined when a conditional denominator is zero. These associations are descriptive and do not validate an error predictor on unfamiliar programs.

The query diagnostic must hold the program body and target slot fixed. For each literal surface body and each fixed target slot, compare its decoded value correctness when that slot is queried with its mean correctness across the other three queries. Retain the full four-target-by-four-query table. Report the site7 pre-query placebo, site8 final-prompt contrast, and site8-minus-site7 contrast with the same component bootstrap. At sites3 and7 the query is future text, so per-query differences that select different target slots can reflect recency/slot differences. They cannot establish query modulation. The other slots can be ancestors of the answer and must not be called irrelevant.

Report whether a decoded graph coexists with a wrong answer and whether query-dependent accessibility appears within the matched bodies. These observations cannot establish that the decoded representation is available to the model's natural downstream pathway, distinguish bad root arithmetic from failure to use values, or establish a dedicated relation code. Computed and literal formats differ in operations, token lengths and positions. The original strong source-value baselines and the small computed-format algebraic gains remain part of the interpretation.
