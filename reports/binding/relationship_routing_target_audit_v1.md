# Prefix-visible relationship target audit

Prepared structural targets only: no learned relationship decoder, activation analysis, model query or causal intervention. Each graph uses only visible assignment versions; the output expression is absent unless explicitly visible at the final checkpoint. Relations are syntactic def-use, strict ancestry and version succession, not numerical equality, functional influence or evidence that a model represents these relationships. Support/prior summaries weight structural groups equally after deduplicating graph states within each group; numeric and naming relatives are not independent replications. Fixed or one-class labels can make later decoding trivial. Graph variation alone does not qualify captures, independent generalization, an ownership mechanism or mechanism C.
