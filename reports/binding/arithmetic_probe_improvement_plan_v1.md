# Arithmetic probe improvement: declared discovery plan

The original global linear probes remain the baseline. Their strong TRAIN fit and weak structural DEV performance motivate a change in probe design, not a claim that dependencies or values are absent. The previously examined DEV cohort is adaptive discovery throughout this follow-up. No optional language-model training, causal patching or sealed final evaluation is authorized by this protocol.

## A. Archived-feature selection

For each original checkpoint, reuse all four archived layers at the answer-preparation site. Compare hidden representations with the existing width-matched character 3–8-gram source representation. Select each backend separately for three objectives: family-macro individual-parent accuracy, family-macro algebraic-relation balanced accuracy, and negative family-macro continuous-value MAE. The four numeric values are now regression outputs; rounded integer accuracy and relations derived from rounded values are secondary diagnostics. The categorical value baseline remains published unchanged.

Use three deterministic folds of whole TRAIN structures, stratified by addition/subtraction/mixed operation family. All numeric, lexical and queried-slot relatives stay together. Each fold fits train-only normalization, weighted principal components and independent ridge outputs. Fixed candidate alphas are 1, 100 and 10,000; retained component ranks are 32, 128 and full numerical rank. Full rank is the ordinary weighted ridge objective up to numerical eigensolver tolerance. This is a constraint on input components, not a supervised reduced-rank regression model. Weighting seeds are 11, 29 and 47, using the previous exponential family weights. Each candidate must have all nine fold/seed observations. Maximize their mean objective; ties favor smaller rank, then larger alpha, then lexicographically larger representation name. This deterministic last tie rule has no scientific interpretation.

Relation eligibility is recomputed from each inner fit partition using at least 12 positive and 12 negative unique numeric bodies. Family metrics omit relation cells with a missing class and retain support counts. All candidate scores are retained; no DEV score participates in selecting a layer, rank or alpha. Persist the complete selection before generating/scoring DEV targets. Refit selected settings on all TRAIN with all three weighting seeds, save coefficients and predictions, and replay the saved parameters. Retain TRAIN, prior and coherent-family-shuffle results. Shuffles stay inside TRAIN and DEV separately; they use the settings selected on real labels. Source settings receive their own TRAIN-only selection. Report each objective's selected decoder separately rather than presenting a single winner across objectives.

There are 45 spectral factorizations per checkpoint for selection (five representations × three folds × three seeds), covering 405 candidate fits. Final refits depend on which representations are selected. Completed fold and final banks resume only under identical source/configuration identities. There are zero new language-model calls in this stage. Saved metadata and completion receipts enter the existing automatic experiment log. CPU jobs run through SLURM and retain allocation bounds, not a cumulative compute cap.

## B. More diverse sources and local dependency probes

Prepare a new source cohort with more canonical structures and varying arithmetic depth. Include one-update calibration separately from the supervised structural cohort; hold new structural development families apart before capture. Exclude every original four-update canonical structure. Use three numeric seeds, neutral lexical renamings, explicit printed queries, and three fixed instruction variants for behavioral calibration. Exact read-time definition IDs must distinguish same-valued variables, overwritten destinations and historical assignments. Validate targets against an independent execution trace.

Capture definition ends and operand-use token spans, plus the global answer-preparation state. Candidate definitions must precede the operand read. Compare shared linear, low-rank interaction and small nonlinear dependency scorers against source/position controls under grouped TRAIN-only selection. The same scorer is reused across operand and assignment positions. Keep calibration behavior, dependency recovery, current-value recovery and algebraic-relation recovery separate. A local readout success supports distributed accessibility and cannot substitute for success at the global answer state.

Before releasing new model capture, require source/oracle validation, native tokenizer span checks, frozen software validation and resumable/checksummed outputs. The local architecture and its exact dimensions must be frozen in a separate configuration before seeing the new development results. Training structure learning curves will use whole families. Higher-capacity success requires matched-capacity shuffled/source controls. The existing editor allocation and other queued/running jobs remain preserved.

## Decisions

Finish A first while preparing B. Use A to assess sensitivity to regularization, rank and archived layer choice. Establish reliable short printed arithmetic before interpreting causal error mechanisms. Broader local probes and fresh structural validation address a different question from the preserved global baseline. New development families are discovery data; an untouched confirmatory cohort will require a separately frozen later protocol.
