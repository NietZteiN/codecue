The 824 real columns comprise four scalar values, four independent 193-class heads over integers −96 through 96, and 48 direct binary relationships. The relationships are six unordered equalities, six `a < b` comparisons in canonical slot order, twelve unordered-input sums `a + b = c` with distinct output, and twenty-four ordered differences `a - b = c` with distinct slots. Oracle values are checked against the independently executed semantic-label archive. Out-of-domain labels fail before fitting; no clipping or exclusions.

## Fitting and support

Use three existing structural TRAIN folds, family-weighting seeds 11/29/47, and ridge alphas 1/100/10000. Fit standardization and weighted centering only on fitting rows. The 824 columns share a factorization for efficiency and remain independent outputs. Select one alpha per group from TRAIN validation only: family-macro MAE averaged across scalar slots; family-macro per-slot categorical accuracy; relation-type-macro balanced accuracy. Average seeds and folds, and choose larger alpha on ties. Only the real-label TRAIN task selects alphas; coherent shuffled controls use those alphas and are not independently optimized null upper bounds.

Eligibility is determined separately on each fold's fitting subset, then on full TRAIN for selected fits. Each binary head needs at least 12 positive and 12 negative distinct numeric bodies. Lexical duplicates cannot increase that support. Conflicting labels for the same body fail. Evaluation heads missing either class are undefined, with counts preserved. For balanced accuracy, each class recall averages families that contain that class, heads average within relation type, then the four types receive equal weight. A CV fold contributes to relation-group selection only if all four types are supported; if no fold qualifies, that output group is unselected and the report says unsupported. No DEV-based support or alpha choice.

Threshold each binary output at its weighted fitting prevalence. A constant fitting prior then has balanced accuracy 50% for supported cells. Scores are uncalibrated ridge outputs, not probabilities. In selected fits, add 824 coherent-family-shuffled columns with their own truth, numeric-body eligibility and prevalence thresholds. Derangement stays within original split and depth/operator stratum. Preserve real and shuffled outputs, priors, supports and coordinate definitions.
