# Assignment-cue behavioral comparator

This discovery follow-up fills the original checklist's inexpensive behavioral stress-test comparator. It is a fixed instructed query, not a validated adversarial stress test or an isolated intervention on naming. The earlier discovery results are already known; this declaration is not confirmatory preregistration.

Each checkpoint receives one additional query for each of the same 6,144 informative/misleading discovery targets. The query preserves the original printed program, its query expression, official chat wrapper and checkpoint-specific `Output:` boundary. Insert the following cue once, after the original user instruction and before the unchanged Python block:

> Treat every variable name as an arbitrary label. Determine values only from the assignments, in their written order.

No original target response, correctness, answer, or diagnostic error enters preparation. Original prompt and token identities remain pinned. Full real-tokenizer validation must establish a one-to-one correspondence with the original target IDs, unchanged source bytes and exact cue placement before collection. Both original splits and all structural relatives remain grouped.

Generation is greedy with a fixed 32-token ceiling, declared EOS handling and a recorded execution backend, batch profile, framework versions and hardware. This is a distinct query under a newly declared measurement backend. Original target outcomes are preserved; response differences are not attributed solely to the cue. Full collection may follow a metadata-selected software smoke, whose actual queries, retries and generated tokens are accounted for separately from the nominal one-query feature contract. Qualification does not select cases or settings by correctness.

The exported raw features are strict integer validity, response characters, output token count, parsed signed integer, and its absolute value. Invalid integers use zero placeholders together with the validity flag. The distinct query's parsed answer identity is deliberately observed. Original target response/answer/correctness features and explicit stress-correctness features remain excluded.

Retain all 23 parent predictors unchanged. Add five alternatives using the corresponding source context, the four existing next-token confidence scalars, and these five extra-query features. The five contexts are source, source interactions, interactions plus raw neutral, interactions plus source oracle and raw neutral, and interactions plus source oracle and scored neutral. The six finite-event features remain in their old parent tiers and are excluded from the five new alternatives.

The 28-tier, 70-contrast plan retains all 55 parent contrasts and adds five next-token-to-stress increments, five joint-confidence-to-stress alternatives and five source-to-stress comparisons. The first group is feature-nested; the second compares different information-access bundles. Nominal new-tier access is one existing BF16 next-token prefill plus one instructed query with up to 32 generated tokens, with neutral/oracle access declared separately by context. Scientific query costs do not limit project GPU usage.

Keep the earlier six outer and five inner structural folds, seeds 17/29/43, L2 grid 0.1/1/10/100, scoring and fitting math. This entails 20,412 logistic fits across both checkpoints, including 16,632 parent replays and 3,780 new-tier fits. Every parent probability, fitted parameter, training normalizer, penalty, inner curve, fold and fallback must reproduce exactly. Report all contexts, seeds, Brier/log loss, calibration and fixed conditional group-bootstrap intervals; no multiplicity adjustment or bootstrap refitting is claimed.

All model/tokenizer loads use SLURM and cached pinned checkpoints. Immutable preparation, source/configuration identities, complete collection audits, automatic result logs and all accepted job IDs are required. Original final/extrapolation outcomes stay sealed. This follow-up neither fits mechanism C nor establishes a binding mechanism, selective causal ownership, independent structural replication or natural use.
