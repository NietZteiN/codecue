# Structural and algebraic relationship decoding

The user explicitly selected both dependency/version relationships and algebraic relationships. The [structural preparation plan](relationship_decoding_plan.md) and its [completed preparation](relationship_preparation_findings.md) remain historical records. This extension adds numeric relationship targets without changing their value-free structural labels. Neither branch has a trained relationship decoder yet.

| Family | Targets | Necessary comparison |
|---|---|---|
| Structural | Directed versioned def-use, transitive ancestry, current/obsolete versions, assignment succession and explicitly visible output ancestry | Surface and structural/position priors, grouped shuffled relations, and equal-value/different-provenance controls |
| Algebraic | Equality, less-than ordering, signed pair differences, `x + y = z` and `x - y = z` over distinct visible slots | Relations computed from independently decoded variable values, plus matched surface, majority and shuffled-target baselines |

Structural dependency and algebraic equality are different relations. Two variables can contain the same value without depending on one another; different dependency graphs can produce the same complete numeric state. Likewise, decoding `x + y = z` does not demonstrate a dedicated relational representation if independently decoded values already support that decision.

All labels refer only to the visible assignment prefix. Numeric targets execute that prefix with a constant-zero output sentinel, retaining actual current values only as supervised targets and for the later value-derived comparison. Future statements and the actual output are not executed. Undefined variables are absent, not assigned false relationship labels. Signed differences are numeric regression targets; equality, ordering and triple relations are separate boolean classification tasks.

The algebraic source bank reuses the same 27 copy-routing components and 18/9 training/development split. Three numeric sampling strata are balanced within each topology: four distinct literals, an explicitly additive initial triple, and an equal pair with different provenance. Sampling strata are not measured relation labels: accidental sums in the uniform stratum and relations changed by later copies must be counted from the actual visible state.

Four numeric instances per stratum, three first-copy variants and two neutral lexical forms produce 1,944 rows. Independent ordinary Python checks complete source traces. These sources share their 81 full graph structures with the earlier routing bank and must not be treated as independent structural replication or pooled to inflate group counts. Full graph components remain split-disjoint within each bank; early partial graphs can legitimately recur across splits.

Validate both structural and algebraic target families on the same numeric-control bank, then capture its representations once at assignment endpoints and a pre-query summary site. This permits direct comparisons on identical examples and avoids redundant model work. Fit controlled linear relation heads and separate value heads on training only; any pair-conditioned or low-rank extension needs a declared capacity comparison. Select sites and hyperparameters using discovery development data, retaining all curves and denominators. Do not supply oracle values, edges, sampling-stratum labels or version labels as hidden-probe inputs.

Report positive and negative structural-group support and prevalence-aware metrics for every boolean relation. Many candidate additive triples will be false; high all-negative accuracy is not useful decoding evidence. Numeric/name relatives, symmetric pairs and permutations of the same algebraic equality are not independent scientific replications. Keep output relevance unavailable before the query and syntactic ancestry separate from functional intervention effects.

These are adaptive discovery diagnostics with fixed destination order, copy-only execution and one final query. No language-model training, causal-mechanism claim, final-outcome evaluation or new-family confirmation follows from target preparation. Selective downstream interventions and frozen unfamiliar-program prediction remain later milestones.
