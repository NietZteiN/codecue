# Additional discovery measurement controls

The primary discovery model frequently emits a small set of negative integers. A counterfactual-compatible answer can therefore arise without a program-specific wrong binding. The new `diagnose-errors` analysis shuffles complete base prediction vectors within family, load, update and split cells. Naming conditions, lexical realizations and the primary/arithmetic pairing move together. The oracle and target program stay fixed.

This control retains the observed answer prior, including invalid outputs. It reports every compatible-label endpoint separately. Singleton strata cannot vary, numeric bases can share parent templates, and model confidence or prompt details within a cell remain uncontrolled. The permutation reference range is a within-cohort descriptive quantity, not a population confidence interval, causal test or multiplicity-adjusted significance result. An observed rate resembling this reference is weak evidence for identifying a binding failure from answer compatibility alone. Exact results and identities are in the generated [pilot report](pilot_report.md) and its linked artifact.

```bash
python -m codecue.binding diagnose-errors --config configs/binding/cpu_discovery_subset_prefill_v2.json
```

The cache-based ridge sensitivity addresses a different issue: the state decoders interpolate training examples but generalize weakly. It evaluates a fixed penalty grid of 1, 100 and 10000, chosen after observing that training/development gap. The feature normalization, raw decoder width, training cases and extraction sites remain unchanged. Current values, previous versions and multisets each retain their own fitted decoder. Surface and three randomized-label tasks use the same penalty at each grid point. Every development naming condition is retained; no final-test labels or activations are used.

```bash
python scripts/94_binding_probe_regularization.py configs/binding/cpu_probe_regularization.json
```

The new stages have distinct names and immutable run identities with the earlier activation source explicitly pinned. Alpha 1 is rerun as a replication check against the earlier saved predictions. The sensitivity artifact reports the full grid; it does not select a mechanism or automatically replace the original fixed-penalty results. A better regularized decoder would still establish only accessible information under that estimator, requiring independent causal specificity and predictive validation for a mechanism claim.
