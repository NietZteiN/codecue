# Queried versus unqueried value accessibility

This adaptive discovery follow-up asks whether a fixed linear readout recovers the requested value better than the other value from the same representation. Earlier work recovered the requested value strongly near answer preparation, while complete current/saved state recovery was weak. Those measurements differ in their targets and capacity. This study directly matches queried and unqueried decoder capacity, labels, data and fitting.

Use only the existing audited Llama 3.1 8B version-2 discovery capture: 9,216 rows, 4,608 reciprocal current/saved query pairs, 18 training and six development structural groups. Both targets exist at every source checkpoint. Keep both query twins at every site. Their queried and unqueried targets exchange places, so their aggregate class histograms match exactly in every naming/split cell. The original template-level positive weights also match within each pair.

The four target heads are queried value, unqueried value, matched shuffled queried value, and matched shuffled unqueried value. Each head has the same 32 classes, 4,096 inputs, 131,104 coefficient/intercept parameters, fitting rows, feature normalization and regularization. The shuffle permutes complete current/saved value pairs among numeric bases within split/template, keeping every naming, lexical, update, placement and query relative together. Verify ordinary and weighted class frequencies and training support. Query role defines the semantic labels; it is not appended as an input feature. Report query-role-by-head and derived canonical-current/canonical-saved cells to expose asymmetries hidden by aggregate marginals.

Fit on neutral training rows only, with the existing template weights for seeds 11, 29 and 47, fixed alpha 100, and the summed weighted squared-error objective. Fit an unweighted training-only StandardScaler, then use the correct weighted centering/intercept for ridge. All new arithmetic is float64. This matches the objective and normalization policy of the earlier readouts, but does not promise bitwise agreement with their potentially float32 intermediate transforms.

Fit all 128 output columns together to share one factorization while retaining independent coefficients for each head. When training rows are fewer than features, use the algebraically equivalent dual Cholesky solve; otherwise use the primal form. The helper must agree numerically with an explicit float64 scikit-learn reference, preserve head independence, and reproduce predictions exactly after parameter serialization. No reduced-rank constraint, PCA, alignment, outcome-guided tuning or learned query-role feature is used.

Evaluate all captured blocks 8, 16, 24 and 31 and all three sites: before the query, the query-line boundary, and the earlier answer-preparation boundary. Surface controls use 4,096 signed character-ngram features with sizes 3–8 from exactly the visible prefix at each site. Fit the three surface sites once each. This gives 15 feature/site banks and three fixed weighting seeds: **45 ridge solves covering 180 equal-capacity heads**. Store every parameter, training identity, label/control mapping and prediction.

The primary descriptive contrast is hidden block 24 at answer preparation on neutral development cases, selected before this run because the earlier queried readout was strong there. All other naming conditions, sites and blocks remain secondary curves. Average each row's correctness difference across the three fixed fits first, then resample its six whole structural groups with 2,000 draws and seed 117. Seeds are sensitivity fits, not independent replications. Intervals condition on saved fits without refitting or multiplicity correction.

Before the query, paired vectors and visible text are exactly identical despite differing future query labels. Thus queried and unqueried empirical ridge objectives are algebraically equal; this is a causal-prefix sanity check, not a test for future-query information. Retain original scores and predictions. Record coefficient/intercept/score differences, top-two score margins, raw argmax agreement and tie-aware agreement using a predeclared absolute score tolerance of 1e−8. A disagreement away from numerical ties fails the check; averaging or canonicalizing heads to manufacture equality is not allowed. Failure of this shared-head task before the query says nothing about whether separate canonical-slot decoders could recover both values.

All split, source, checksum, complete-label, query-twin and histogram guards precede numerical fitting. Loading captures revalidates their full row metadata, which includes original response fields; those responses and correctness are never readout features. No language model, tokenizer or new generation is needed. Run the numerical work through SLURM, record the allocation and library/thread settings, and preserve immutable configuration/source/results plus automatic experiment logging. Final/extrapolation outcomes remain sealed.

Post-query selectivity can reflect query-dependent accessibility, task complexity or answer preparation. It does not distinguish tracking from reconstruction, prove that an unqueried value is absent, identify ownership coding, or demonstrate natural causal use. The old answer-preparation capture predates the later formatting-space correction and is not the subsequent digit-intervention boundary. This study does not qualify mechanism C or final unfamiliar-program forecasts.
