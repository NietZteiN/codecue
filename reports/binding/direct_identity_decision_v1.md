# Direct event identity: scientific decision

The new direct readouts recover some complete write and parent identities through a fixed owner/version codebook. The stronger source comparator changes the parent conclusion: parsed SOURCE owners plus weighted TRAIN version priors recover all four parents on 40.000% of DEV programs, exceeding the hidden joint heads at 24.630% (8B) and 30.093% (34B). Hidden whole-write identity scores exceed that comparator. This supports a bounded accessibility result; it does not establish a binding mechanism or independent owner/version representations.

The fixed primary below is layer 24/site 7 and averages all three weighting seeds 17/29/43. Write and parent endpoints each require all four corresponding event identities correct; the all-eight endpoint requires both sets correct. Each seed evaluates 1,440 rows in 15 DEV graph families, 96 dependent relatives per family. Row and equal-family estimates agree because family sizes are equal. No interval or outcome-selected layer is introduced.

The TRAIN-only identity prior and prefix-sham task both score 0% on these whole joint endpoints at the fixed primary. The prefix sham changes version-class difficulty and marginal frequencies and need not form a lawful multi-event SSA graph, so a direct-minus-sham gap cannot isolate a causal identity representation. The syntax-owner comparator is stronger on the parent joint endpoint and must remain in the comparison.

The marginal-argmax rows combine the largest owner-score sum and largest version-score sum from each joint score table. The coherent labels and common linear ridge operator make the separately fitted component scores equal those marginal sums up to floating point error. Across 1,920 event/comparator metadata cells, every residual diagnostic covers all 1,440 DEV rows; the largest recorded owner residual is 6.08513e-13 and the largest version residual is 8.17124e-13. These were read from audited JSON diagnostics without applying parameters again or selecting rows. Thus 34B's 45.093% parent marginal decision can exceed the 40% source prior while its 30.093% joint decision does not. That difference concerns decision rules on shared scores. It is not evidence for independent representations or a clean capacity comparison; joint heads have 16 nominal outputs versus 8 component outputs, and ridge scores are uncalibrated.

Current/obsolete strata describe the real source at capture time. No previous-version numeric value or behavioral use is decoded here.
