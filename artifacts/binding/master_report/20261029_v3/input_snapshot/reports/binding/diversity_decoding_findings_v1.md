# Slot-complete overwrite relationship decoding

Both checkpoints completed the fixed discovery grid and passed actual saved-parameter, scientific-metric and control-marginal replay audits. These are descriptive decoding results, with no behavioral reliability qualification or causal mechanism claim.

Each model uses 5,760 source cases: 4,320 TRAIN rows in 45 canonical SSA graph families and 1,440 DEV rows in 15 families. Each family contains 96 related rotation/numeric/lexical/query cases. The three overwrite-count profiles contribute twenty families each. Novelty is relative to the two named prior graph banks, and all relatives keep their declared split.

All four final version classes occur in every variable slot in both splits. This improves source coverage; the table below measures whether the fixed decoders recover them. It does not presume that repaired source support supplies a general version-tracking ability.

Layer 24 at the final-assignment site 7 was nominated before capture for both checkpoints. Every table point averages all three fixed weighting seeds 17/29/43. No favorable layer, class or seed subset replaces the primary.
