# Explicit query timing and earlier copy-site discovery

This continuation advances the tracking/reconstruction branch and the earlier relevant copy implicated by the swap failures. It is a core discovery study, not an automatic launch of optional training, unlearning or a separate explanation-transfer paper. The previous computed-family gates and negative late-reset result are retained. Generated final/extrapolation outcomes remain sealed.

The pinned Llama 3.1 8B checkpoint and neutral literal/copy source bank are reused. No cases are chosen by their observed correctness. Three instruction variants are fixed before inference; each has both neutral lexical realizations and every mapping/query condition. Numeric relatives and instruction variants are not independent structural replications. Results are descriptive discovery measurements, with no confirmed-layer, population-significance or general-memory-algorithm claim.

## Query timing

The bank has 2,592 prompt variants: all 432 original ownership/version sources × three instruction variants × early/late target cues. The displayed code contains assignments only. A target line before the code and another after it exchange the actual variable name and `not_set`; exactly one line supplies the target. The instructions define the placeholder. Both timing variants have identical assignments and requested values. Actual-tokenizer preflight must establish identical full token multisets, lengths and capture positions within every early/late pair.

Capture raw blocks 0, 8, 16, 24 and 31 at the last relevant copy, the end of all assignments, the initial scratch literal and the assistant prefill. For late cues, every earlier vector must be exactly invariant across the two future query identities; for early cues, that equality is not expected. Report query-sensitivity distances at every site/layer without treating different residual scales as information measures. The initial-literal site controls for query information already present before meaningful execution. Whole-answer greedy accuracy, invalid outputs and paired early-only/late-only changes are the behavioral endpoints. No hidden-state interventions or probes are requested in this phase. Digit-alignment rates are reported rather than used to discard formatting failures; prefill-logit/first-generation consistency remains mandatory.

Revealing a query earlier can change attention, reading strategy or the task distribution. An accuracy advantage or query-dependent activation alone does not prove online state tracking, query-time reconstruction or information absence.

## Earlier copy

The bank has 1,944 prompt variants: all 216 original ownership sources × three instructions × three source forms. Forms are the exact original, commuting the second-variable initialization with saving the first variable, and consistently renaming the temporary to `cache`. The transformations preserve the complete canonical final state, statement count and literal exposure. Reordering must also preserve the token multiset. Capture positions and total token lengths must match between donor/recipient forms. The original instruction-0 anchors must have exactly their previously recorded prompt IDs.

Every original/alternate pair is patched in both directions, yielding 2,592 directed pairs. The main site is the final token of the earlier assignment that restores the second variable from the temporary. The original input contains a copy or self-copy there, not a direct answer literal. The other-variable and unswapped queries remain included; no correct/error cases are selected. The primary contrast is correct digit versus the other binding, and patched accuracy is reported alongside the exact same-batch unpatched accuracy. The already observed swapped second-variable cell is nominated for detailed plots before inference, with all other cells and all instruction-specific results saved.

At every raw block retain primary copy-end vector replacement, norm-matched unrelated-position perturbation, donor answer-vector replacement, identity sham and three norm-matched random directions (11, 29, 47). Match effective norms after BF16 rounding within the fixed 3% tolerance. Every baseline must be digit-aligned before these next-token interventions. Every actual destination vector must equal its same-batch replay; all identity shams must preserve that replay. Final-block earlier-token controls must leave the answer unchanged, and final answer-vector transfers must copy the donor digit. The latter is a software answer-copy control, not evidence of a binding mechanism.

The complete finite workload is 90,720 intervention forwards, all five blocks and all seven conditions. Natural donor states and semantic equivalence do not prove that a transferred vector is a naturally used binding representation. A successful repair could introduce an alternative route or steer the answer. A failed local patch is inconclusive about a distributed pathway. These results do not establish a general explanation-transfer method or its separate-paper contribution.

## Execution and artifacts

The datasets and complete independent Python execution traces are validated before inference. Configurations are `query_timing_v1.json` and `copy_path_v1.json` under `configs/binding/competition/`. Frozen source/configuration pointers, scheduler IDs, raw greedy outputs, activation caches, replays, chunk checksums and final audits live under `artifacts/binding/timing_and_copy/`.

Both studies use BF16 SDPA, batch 108 and fixed padding width. This divides every registered baseline and pair count, keeping physical/rotary positions and batch geometry fixed. The timing job can use A30/H100/H200 including the A30 development queue; the larger patch matrix prefers H100/H200 for throughput, with other eligible hardware available if queue conditions justify it. The earlier measured A30 batch-144 short-prompt peak was about 18.5 GiB, supporting the batch-108 memory estimate. Actual hardware and peak memory are recorded. No project GPU-hour or application time cap applies; only granted scheduler limits apply. Finite workloads exit on completion and preserve resumable artifacts.
